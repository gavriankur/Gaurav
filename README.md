# Gaurav

Festival artwork and captions for Gaurav Dua.

Live site: https://gavriankur.github.io/Gaurav/

Daily publishing: 08:17 Asia/Kolkata, subject to GitHub scheduler delays. Prepared entries release five days before the occasion. Diwali is an early sample. This workflow does not generate artwork automatically. Edit posts.json to add prepared entries and images; run python build.py to preview the public folder.
